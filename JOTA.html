Getting a license

GB8 BAS

In the UK, you’ll need an amateur radio licence to transmit on amateur radio frequencies. Start by learning the basics and finding out about the Foundation licence exam. The RSGB has beginner resources, and BARC are planning to run a course later this year. Check their website (link in the top title) for updates!
